## Instalasi

### Prasyarat

Pastikan Anda sudah memasang **Node.js versi 20 atau lebih baru**. Cek versi Node yang terpasang dengan perintah berikut:

```bash
node --version
```

Jika versinya di bawah 20, perbarui Node.js terlebih dahulu melalui [nodejs.org](https://nodejs.org) atau pengelola versi seperti `nvm`.

### Memasang tarik

Pasang `tarik` secara global menggunakan npm:

```bash
npm install -g tarik
```

Setelah selesai, pastikan instalasi berhasil:

```bash
tarik --version
```

### Inisialisasi

Masuk ke direktori proyek Anda, lalu jalankan:

```bash
tarik init
```

Perintah ini akan menyiapkan konfigurasi awal yang dibutuhkan `tarik` di proyek tersebut. Setelah itu, `tarik` siap digunakan.

> **Catatan:** Jika muncul galat izin (permission error) saat instalasi global, coba gunakan pengelola versi Node seperti `nvm` alih-alih menjalankan npm dengan `sudo`.
