## Instalasi

### Prasyarat

Pastikan Anda sudah memasang **Node.js versi 20 atau lebih baru**. Cek versi Node yang terpasang:

```bash
node --version
```

Jika versinya di bawah 20, perbarui Node.js lewat [nodejs.org](https://nodejs.org) atau pengelola versi seperti `nvm`.

### Memasang tarik

Pasang `tarik` secara global dengan npm:

```bash
npm install -g tarik
```

Lalu pastikan instalasi berhasil:

```bash
tarik --version
```

### Inisialisasi

Masuk ke direktori proyek Anda, lalu jalankan:

```bash
tarik init
```

Perintah ini menyiapkan konfigurasi awal `tarik` di proyek tersebut. Setelah itu, `tarik` siap dipakai.

> **Catatan:** Jika muncul galat izin (permission error) saat instalasi global, pakai pengelola versi Node seperti `nvm` alih-alih menjalankan npm dengan `sudo`.
